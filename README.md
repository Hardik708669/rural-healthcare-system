# HealthConnect Rural - AI-Powered Healthcare Continuity System

An AI-powered rural healthcare continuity platform that ensures uninterrupted access to essential medical care in under-served and geographically isolated areas.

## 🚀 Features

### Core Functionality
- **AI-Driven Telemedicine**: Remote diagnosis, triage, and consultations
- **Multilingual AI Assistant**: Voice/chatbot support in multiple Indian languages
- **Symptom Checker**: AI diagnostic assistant with emergency detection
- **Behavioral Reminders**: Automated patient follow-ups and medication reminders
- **Offline-First Design**: Local data caching with sync when connectivity returns
- **Health Monitoring Dashboard**: Real-time village-level health metrics for authorities

### Key Components

#### 1. Dashboard
- Role-based interface (Patient, Health Worker, Authority)

## 🛠 Technology Stack

- **Frontend**: React 18 + Vite
- **Styling**: Tailwind CSS
- **Routing**: React Router DOM
- **Icons**: Lucide React
- **State Management**: React Hooks
- **Offline Storage**: LocalStorage

## 📱 Installation & Setup

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd healthconnect-rural
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```
